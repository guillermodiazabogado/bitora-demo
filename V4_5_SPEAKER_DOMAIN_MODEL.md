# BITORA V4.5 - Speaker Domain Model

Tablas principales:

- `speaker_profiles`
- `speaker_private_details`
- `speaker_profile_versions`
- `speaker_event_assignments`
- `speaker_activity_assignments`
- `speaker_documents`
- `speaker_access_tokens`

Los perfiles pertenecen a una organizacion. Las asignaciones pertenecen a organizacion y evento. Las asignaciones de actividad validan que la actividad pertenezca al evento.
