# V4.3 Verification Model

La verificacion publica usa token opaco. Solo se almacena `token_hash` y `token_hint`.

Respuesta publica:

- valido/invalido;
- estado;
- numero;
- participante visible;
- evento;
- organizacion;
- tipo;
- fecha de emision.

No expone email, telefono, documento, auditoria ni IDs internos.
