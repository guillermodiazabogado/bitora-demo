# V4.3 Template Specification

Las plantillas usan un esquema estructurado con claves permitidas:

- `title`
- `subtitle`
- `body`
- `footer`
- `location`
- `signatures`

Variables permitidas:

- `participant_name`
- `event_name`
- `activity_name`
- `certificate_type`
- `issuance_date`
- `certificate_number`
- `organization_name`
- `location`
- `eligibility_result`
- `closure_reference`
- `template_version`
- `verification_code`

Variables desconocidas o contenido peligroso se rechazan.
