# Asignación de agentes

La sesión permite cuatro agentes activos incluyendo al coordinador; se trabajará por oleadas.

| Agente real | Oleada inicial | Restricción |
|---|---|---|
| Coordinador `/root` | Git, auditoría, backlog, integración y tablero | No publicar ni desplegar |
| `/root/arquitectura_backend` | Backend, persistencia, negocio y Edge | Sin editar archivos compartidos en reconocimiento |
| `/root/frontend_operacion` | Frontend, Command Center, mapas y operación | Sin editar archivos compartidos en reconocimiento |
| `/root/seguridad` | Seguridad, QA y DevOps | Sin editar archivos compartidos en reconocimiento |

Las especialidades restantes se asignarán por oleadas a estos agentes reales; no se simulan ocho procesos simultáneos.
