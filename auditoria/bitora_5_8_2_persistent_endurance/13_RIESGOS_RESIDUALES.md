# Riesgos residuales

- Docker Desktop requiere corrección administrativa del runtime antes del preflight.
- Registrar una tarea programada cambia persistentemente el host y requiere autorización.
- 13,9 GiB de RAM es un margen ajustado: deben fijarse límites y verificarse memoria libre antes de iniciar.
- Vouchers, leads, vehículos y Edge todavía no forman parte de la mezcla prolongada.
- La tarea con usuario interactivo no sobrevive a logout/reinicio; una interrupción invalida las seis horas continuas.
- Hardware, red, cámaras y operadores reales no fueron probados.
