# BITORA V4.9 Automation Engine

V4.9 introduces controlled automation definitions.

Supported trigger identifiers:
- REGISTRATION_CONFIRMED
- ACTIVITY_REMINDER
- ATTENDANCE_RECORDED
- ELIGIBILITY_CLOSED
- CERTIFICATE_ISSUED
- SURVEY_OPENED
- SCHEDULE_CHANGED

Rules:
- No arbitrary code.
- Automations start as DRAFT.
- Activation requires backend permission.
- Restored automations are paused.
