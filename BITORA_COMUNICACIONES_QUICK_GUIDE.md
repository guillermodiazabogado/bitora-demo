# BITORA - Guia rapida Comunicaciones

## Como ingresar

Entrar con usuario de Comunicaciones o Productor autorizado.

## Pantalla principal

Usar la pestana `Comunicaciones`.

## Acciones principales

- Revisar proveedor activo.
- Crear borrador.
- Seleccionar audiencia del evento.
- Previsualizar variables.
- Enviar o programar si tiene permiso.
- Reintentar fallidos.
- Revisar historial y metricas.

## Errores comunes

- Enviar sin consentimiento.
- Usar telefono sin codigo de pais.
- Usar plantilla WhatsApp no aprobada.
- Confundir safe mode con produccion real.

## Que no hacer

- No cargar API keys en pantallas no autorizadas.
- No enviar a audiencias masivas sin aprobacion.
- No copiar datos personales a herramientas externas.

## Escalar a

Super Admin para proveedores. Soporte tecnico para webhooks, colas o errores de entrega.
