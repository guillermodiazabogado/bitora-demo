# BITORA V4.10 Metric Definitions

Las definiciones se exponen por API en:

- `GET /api/events/{event_id}/analytics-v4/definitions`

Reglas:

- no se muestran numeros sin definicion;
- no se mezclan organizaciones;
- no se mezclan eventos;
- no se infiere asistencia sin validacion;
- no se expone PII por defecto;
- Safe Mode y Live Mode se reportan separados.
